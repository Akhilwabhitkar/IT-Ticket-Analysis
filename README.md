# IT Ticket Analysis

## 📌 Project Overview

**IT Ticket Analysis** is a data analysis and dashboard project focused on understanding the performance of IT support ticket management.

The project analyzes IT ticket data to identify patterns and trends in **ticket volume, request categories, priorities, resolution time, ticket status, and customer satisfaction**. The analysis helps understand how effectively IT support teams are handling user issues and where improvements can be made.

## 🎯 Objectives

- Analyze the overall volume of IT support tickets.
- Identify the most common types of IT issues.
- Analyze ticket distribution based on priority and category.
- Measure average ticket resolution time.
- Analyze customer satisfaction levels.
- Identify areas where IT support performance can be improved.
- Present important findings through an interactive dashboard.

## 📊 Key Analysis

The project includes analysis of:

- Total IT Tickets
- Ticket Categories
- Request Priority
- Ticket Status
- Average Resolution Time
- Average Customer Satisfaction
- Category-wise Ticket Performance
- Overall IT Support Effectiveness

## 📈 Dashboard

An Excel dashboard was created to provide a clear visual representation of IT ticket performance and help identify important trends and insights.
